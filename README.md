# Oil Painting Mondays Website

This project is a simple static website built from the project documentation found in `docs/`.

## What it includes

- A Vite-powered content-driven website
- Markdown-based pages imported from `src/content`
- A navigation structure inspired by the docs
- A gallery preview with sample painting cards
- A contact form that opens a pre-filled email draft

## Run locally

```bash
npm install
npm run dev
```

Open the local host URL shown by Vite.

## Build

```bash
npm run build
```

## Notes

site uses plain markdown text converted into `src/content/`.
